# Lanterns

Lanterns is a true-or-false reasoning game set in a night sky. Each round shows all twenty lanterns from the selected difficulty bank. A bank has twenty lanterns.

## Goal

Read each statement and choose its true state:

- **Lit** means that the statement is true.
- **Dark** means that the statement is false.

Classify all ten lanterns. The game reveals the score and explanations at the end. Seven correct answers pass the round.

## Round rules

1. The game shows twenty unique lanterns in a random order. The player classifies any ten.
2. Every round contains nine independent statements and one linked statement.
3. The linked lantern refers to an independent lantern that is also in the round.
4. Select one lantern to read its statement. Only one statement can be open at a time.
5. Choose Lit or Dark in the answer step. The answer is final for that round.
6. The game does not show if an answer is correct until all ten answers are locked.
7. The result shows the score, the correct state, and an explanation for each statement.

## Difficulty

- **Easy** uses direct facts, basic number work, and simple logic.
- **Medium** uses number patterns, factual checks, and two-step reasoning.
- **Hard** uses multi-step mathematics, scientific reasoning, and formal logic.
- **Tough** uses conditional logic, probability, number theory, and longer deductions.

Difficulty comes from the reasoning required. A statement must have one clear truth value. A pattern question must state its rule. A connected statement must be solvable from a clue in the same round.

## Categories

The bank uses science, technology, history, mythology, mathematics, geography, general knowledge, logic, and random facts. A dated current-affairs clue may be added when the fact has a clear date and a reliable source. Each lantern shows its category before the player opens it.

## Scoring

The game checks each answer against the statement's truth. It then counts correct answers and calculates accuracy.

- 10 correct: perfect score.
- 7 to 9 correct: pass.
- 0 to 6 correct: not passed.

The game stores round totals and the best score for each difficulty in local browser storage.
